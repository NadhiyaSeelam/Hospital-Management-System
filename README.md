\# 🏥 Hospital Appointment Management System



\## 📌 Overview

This project is a \*\*Hospital Appointment Management System\*\* developed collaboratively by a team of five developers.

The system includes the following modules:

\- Patient Registration

\- Doctor Management

\- Appointment Scheduling

\- Appointment History

\- UI Styling \& Design



The project demonstrates \*\*Git collaboration practices\*\* with feature branches, commits, merges, and controlled integration.
